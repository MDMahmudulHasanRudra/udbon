# Udbon

Company website for **Udbon** (উদ্ভব: Inauguration · Awakening · Beginning), business software made in Bangladesh.

## Products

- **Chithii AI**: one inbox for WhatsApp, Messenger, Instagram and Telegram, with AI replies in Bangla, English and Banglish ([chithii.com](https://chithii.com))
- **Maxr CRM**: clients, leads and sales pipeline
- **SR E-commerce**: catalogue, orders, bKash/SSLCOMMERZ payments and courier booking

## Structure

```
site/
  index.html      the whole website (HTML, CSS and JS in one file)
  assets/         logo files (full, mark, white version)
logo/             original logo
```

## Run locally

```
python -m http.server 5173 --directory site
```

Then open http://localhost:5173.
